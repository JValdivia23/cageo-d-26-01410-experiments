# cageo-d-26-01410-experiments

Reproducible experiments for the Computers & Geosciences manuscript **CAGEO-D-26-01410** ("Spectral-Domain Local Statistics with Missing-Data Support for Cartesian and Polar Grids"). This repository contains the code and frozen results behind the manuscript's numerical evaluation and performance sections, as implemented in [`dct_toolkit`](https://github.com/JValdivia23/dct_toolkit) v1.0.0. It is a standalone copy: no other checkout is needed to inspect the code or run the test suite.

## What is in this repo

- `experiments/scripts/` — one script per experiment (1D boxcar agreement, boundary comparison, 2D radar Gaussian statistics, matched radar statistics benchmark, range-adaptive loop comparison, 3D wind boxcar statistics, large-array mean check, figure exporters) plus the shared provenance helper `_review_common.py` and figure helper `_review_figures.py`. Scripts are verbatim copies; no numerical code was changed for this repository.
- `experiments/tests/` — 390-test pytest suite (numerics, provenance, saved-output checks, figure checks). Tiny synthetic controls stand in for full campaigns; the suite never launches a benchmark by itself.
- `experiments/results/` — frozen outputs of the seven selected runs (see below), plus the retained submitted v0.5.0 historical results. Nothing in `results/` is regenerated by the tests.
- `manuscript/` — read-only reference snapshot (`main.tex`, `references.bib`, `figures/round1/` assets) that the figure/manuscript cross-check tests read. It is verification evidence, not an editable workspace.
- `experiments/README.md` — the full protocol: per-experiment definitions, selected-run inventories, and the original environment notes.

## Environment

Verified runtime: **Python 3.11.13, NumPy 2.4.4, SciPy 1.17.1, Astropy 8.0.2**, ship with Matplotlib 3.10.8, Pillow 12.2.0, and cmweather 0.3.2 for figure exports; xarray/netCDF4 are used to read the radar file. Measurements are x86_64 under Rosetta 2, single-threaded (`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 NUMEXPR_NUM_THREADS=1`).

The experiments pin **dct_toolkit v1.0.0, commit `9cdf40f6ae02a48aa4c6f1eca07de0df6c72935c`**. `_review_common.py` SHA-256-checks all nine toolkit source files against this commit and refuses to run against any other code, so an editable install with the same version string cannot silently leak in. Use this isolated runtime (does not modify any other checkout):

```bash
PYTHON=/Users/java1127/anaconda3/envs/dct-publish/bin/python   # or any CPython 3.11 env with the packages above
TOOLKIT_REPO=/path/to/dct_toolkit                               # only needed to build the pinned archive
REVIEW_RUNTIME=$(mktemp -d)                                     # fresh runtime directory
mkdir -p "$REVIEW_RUNTIME/toolkit" "$REVIEW_RUNTIME/deps"
git -C "$TOOLKIT_REPO" archive 9cdf40f6ae02a48aa4c6f1eca07de0df6c72935c | tar -xf - -C "$REVIEW_RUNTIME/toolkit"
"$PYTHON" -m pip install --no-deps --target "$REVIEW_RUNTIME/deps" astropy==8.0.2 astropy-iers-data==0.2026.10.19.0.52.1 pyerfa==2.0.1.5 PyYAML==6.0.3 packaging==26.3
export DCT_TOOLKIT_SOURCE="$REVIEW_RUNTIME/toolkit"             # contains dct_toolkit/ at top level
export PYTHONPATH="$REVIEW_RUNTIME/toolkit:$REVIEW_RUNTIME/deps"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 NUMEXPR_NUM_THREADS=1
```

## Data access (IC-3)

The raw radar NetCDF is **not** in this repo: the QCed COW file's upstream QC procedure, public access route, and redistribution permission are unverified. Do not redistribute it. See [`experiments/data/README.md`](experiments/data/README.md) for the file identity (SHA-256 `f1e45c26da3002c31cfea1e62ece5a40c18a668d374193205daf793f41a4fae0`, `DBZHC` field, sweep 12, 720 × 1180) and point `REAL_RADAR_PATH` (or `--radar-path`) at a copy you obtained from the author:

```bash
export REAL_RADAR_PATH=/path/to/cfrad_QCed_20220223_023027.051_to_20220223_023410.833_COW1high_SUR.nc
```

Without the radar file, only the synthetic 1D/3D experiments and the pure unit tests run; radar-dependent tests will fail on the missing input.

## How to verify

From the repo root, with the environment above:

```bash
"$PYTHON" -B -m pytest -q -p no:cacheprovider experiments/tests
```

Full check of the frozen runs and the manuscript text (sets the result directories the saved-evidence tests read):

```bash
export REVIEW_RESULT_DIRS=experiments/results/round1/1d_boxcar/lead-review-1d-20261027:experiments/results/round1/2d_radar_gaussian/lead-review-radar-exact-only-20261027:experiments/results/round1/3d_wind_boxcar/lead-review-3d-matched-20261027
export LARGE_MEAN_RESULT_DIR=experiments/results/round1/3d_large_boxcar_mean/quick-large-mean-1gib-20261027
export RADAR_BENCHMARK_RESULT_DIR=experiments/results/round1/2d_radar_statistics_benchmark/radar-matched-statistics-20261102
export RADAR_LOOP_RESULT_DIR=experiments/results/round1/2d_radar_range_loops/radar-range-loops-20261103
"$PYTHON" -B -m pytest -q -p no:cacheprovider experiments/tests
```

Two provenance checks (`test_review_outputs.py` source-identity checks and `test_wind_figure.py` presentation-revision check) compare against the immutable CAGEO publication-history commits `c66106488a4e17bfb45260f4764106c5682254de` / `f27468f21c5e1ab931736dce4239a0dcf9374083`. Fresh clones of this repo do not contain those commits, so `experiments/tests/conftest.py` skips just those tests (reported as `skipped`) instead of erroring; the remaining numeric, saved-output, and figure tests are unaffected. All other tests run standalone.

## Rerunning an experiment

Commands run from the repo root. Never overwrite a frozen run: always pass a new `--run-id`. Run benchmarks one at a time and not concurrently with other CPU-heavy processes.

```bash
"$PYTHON" -B experiments/scripts/generate_1d_boxcar_validation.py --mode full
"$PYTHON" -B experiments/scripts/generate_2d_radar_gaussian_validation.py --controlled-gap --repeats 3 --warmups 1   # needs REAL_RADAR_PATH
"$PYTHON" -B experiments/scripts/generate_3d_wind_boxcar_validation.py --mode all --cases small20,baseline_complete,baseline20,baseline50,larger20,narrow20,broad20,plane_control --repeats 3
"$PYTHON" -B experiments/scripts/benchmark_2d_radar_statistics.py --run-id radar-statistics-new                     # needs REAL_RADAR_PATH
"$PYTHON" -B experiments/scripts/benchmark_2d_radar_range_loops.py --run-id radar-loops-new                        # needs REAL_RADAR_PATH
```

Figure exports (`--figure-only`) write `manuscript/figures/round1/<figure>/` inside this repo; see `experiments/README.md` for the exact commands and their verification side effects.
