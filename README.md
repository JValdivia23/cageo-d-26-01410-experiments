# cageo-d-26-01410-experiments

Reproducible experiments for the Computers & Geosciences manuscript **CAGEO-D-26-01410** ("Spectral-Domain Local Statistics with Missing-Data Support for Cartesian and Polar Grids"). The current revision uses [`dct_toolkit`](https://github.com/JValdivia23/dct-toolkit) **v2.0.0**, commit `7ff29e998dd1102d3fef2a84050402e86dc7ef67`. Its full sampled Gaussian default is separate from the intentionally matched four-sigma radar benchmark. Frozen v1.0.0 and submitted v0.5.0 sources/results remain unchanged, not relabeled. This standalone copy needs no other manuscript checkout for current calculations or applicable tests; historical Git comparisons retain their explicit history requirements.

## What is in this repo

- `experiments/scripts/` — 1D boxcar/boundary studies, sampled-Gaussian radar control and explicit double-loop comparison, archived analytical-response radar studies, 3D wind statistics, large-array mean check, and figure exporters, plus the shared provenance and figure helpers. Scripts are verbatim copies; no numerical code was changed for this repository.
- `experiments/tests/` — numerical, provenance, saved-output, current-manuscript, and figure checks. Tiny synthetic controls stand in for full campaigns; the suite never launches a benchmark by itself. The standalone compatibility `conftest.py` handles only absent manuscript-history commits and the original absolute-path assertion.
- `experiments/results/` — frozen current runs and retained earlier comparisons (see below), plus the submitted v0.5.0 historical results. Nothing in `results/` is regenerated by the tests.
- `manuscript/` — read-only reference snapshot (`main.tex`, `references.bib`, `figures/round1/` assets) that the figure/manuscript cross-check tests read. It is verification evidence, not an editable workspace.
- `experiments/README.md` — the full protocol: per-experiment definitions, selected-run inventories, and the original environment notes.

Each run directory holds `comparison.csv`, `settings.csv`, and benchmark CSVs where applicable (`benchmark_runs.csv`, `benchmark_summary.csv`), plus supporting diagnostics (`coverage.csv`, `support_diagnostics.csv`, `support_by_range.csv`, `application_counts.csv`, `threshold_sensitivity.csv`, `interior_agreement.csv`, `profiles.csv`, `truth_errors.csv`). No smoke runs, failed runs, or large intermediates (`.npz` arrays) are included.

The current radar comparison defines **standard spatial convolution** as the explicit implementation that visits every azimuth–range output cell in nested Python loops in each ordered axis stage, using a NumPy dot product per neighbourhood. Both implementations retain the same four-sigma samples, boundaries, normalization, and three-filter workload. Fresh speedups are 48.1/45.1 at W5/W15 (rounded 45–48 in the Abstract), specific to this Python baseline. The full default needs no larger transforms or extra passes on a fixed grid, but its preparation and total runtime were not measured. No old and new medians are mixed.

The main radar presentation selects two implementations for clarity, not because SciPy cannot implement the operator. Table 11 selects 20 of the 30 new measurements; equivalent composed SciPy calculations remain auxiliary. All earlier code and measurements are preserved. The 3D refresh has 120 new measurements for the original eight cases and five methods. Cartesian maxima now round to 47/40/five over NumPy/Astropy direct/Astropy FFT. Specialized SciPy remains faster; narrow-window Astropy direct and DCT medians are nearly equal. These are new host measurements, not evidence of a release-caused performance improvement. See `experiments/README.md` for all protocols, values, and historical evidence.

The selected-run inventory above identifies the current manuscript evidence. Retained historical runs keep their original source hashes, measurements, and toolkit versions; publishing the archive does not rerun or relabel them.

## Environment

Verified runtime: **Python 3.11.13, NumPy 2.4.4, SciPy 1.17.1, Astropy 8.0.2**, ship with Matplotlib 3.10.8, Pillow 12.2.0, and cmweather 0.3.2 for figure exports; xarray/netCDF4 are used to read the radar file. Measurements are x86_64 under Rosetta 2, single-threaded (`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 NUMEXPR_NUM_THREADS=1`).

The current runner `experiments/scripts/run_review_v2.py` uses **v2.0.0** through `_review_v2_common.py`, checking all ten released source files. It explicitly reuses frozen numerical functions, changing only release/provenance/output bindings and untimed worker launching. Set `DCT_TOOLKIT_V2_SOURCE` to an extraction of `7ff29e9`; the complete commands are in the opening section of `experiments/README.md`. Figure 1's full-default export is in `manuscript/figures/round1/v2.0.0/visual_pipeline/`. Figures 2–4 retain their original sidecars, with profiles/full arrays revalidated rather than re-exported.

The commands below instead reconstruct the **archived v1.0.0 runtime**, commit `9cdf40f6ae02a48aa4c6f1eca07de0df6c72935c`. `_review_common.py` and all frozen drivers remain pinned to that release. This runtime is still required for the legacy tests and old Gaussian calls; do not replace its source beneath saved measurements. New-release tests run in separate child interpreters using `DCT_TOOLKIT_V2_SOURCE`.

```bash
PYTHON=/Users/java1127/anaconda3/envs/dct-publish/bin/python   # or any CPython 3.11 env with the packages above
TOOLKIT_REPO=/path/to/dct_toolkit                               # only needed to build the pinned archive
```

## Rerunning an archived v1.0.0 experiment

Commands run from the repo root. Never overwrite a frozen run: always pass a new `--run-id`. Run benchmarks one at a time and not concurrently with other CPU-heavy processes.

```bash
"$PYTHON" -B experiments/scripts/generate_1d_boxcar_validation.py --mode full
"$PYTHON" -B experiments/scripts/generate_2d_radar_gaussian_validation.py --controlled-gap --repeats 3 --warmups 1   # needs REAL_RADAR_PATH
"$PYTHON" -B experiments/scripts/generate_3d_wind_boxcar_validation.py --mode all --cases small20,baseline_complete,baseline20,baseline50,larger20,narrow20,broad20,plane_control --repeats 3
"$PYTHON" -B experiments/scripts/benchmark_2d_radar_statistics.py --run-id radar-statistics-new                     # needs REAL_RADAR_PATH
"$PYTHON" -B experiments/scripts/benchmark_2d_radar_range_loops.py --run-id radar-loops-new                        # needs REAL_RADAR_PATH
"$PYTHON" -B experiments/scripts/benchmark_2d_radar_gaussian_double_loop.py --run-id radar-gaussian-double-loop-new # archived v1.0.0 four-sigma comparison; needs REAL_RADAR_PATH
```

Figure exports (`--figure-only`) write `manuscript/figures/round1/<figure>/` inside this repo; see `experiments/README.md` for the exact commands and their verification side effects.
